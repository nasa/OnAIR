# Community List of Plugins and Services

At it's core, OnAIR is a framework for AI research: it provides data source interfaces, data flow, and plugin architecture meant to make research easier.
We provide a handful of plugins and services to demonstrate these capabilities.

OnAIR is not intended to be a repository of third-party plugins and services.

We do, however, want to recognize the work others have put into their own plugins and services.
We also would like to provide the community with a starting place to discover new plugins and services.

If you have a plugin or service that you would like added to this list, please read the "Contributing" section of the [readme](README.md).
Submit a pull request with your link added to the appropriate section below with a short (less than one sentence) description.

> [!CAUTION]
> The OnAIR team has not reviewed or vetted any of the code linked below.
> We make absolutely no guarantees about it: the code may be malicious and do real harm to your system.
> Use at your own risk.
